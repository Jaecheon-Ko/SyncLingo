# SyncLingo

유튜브 영상과 영어 자막을 받아, 문장을 터치하면 영상이 그 지점으로 이동하는 **영어 학습용 안드로이드 앱**입니다. 개인 학습용으로만 사용하세요.

## 설치
[최신 릴리스](../../releases/latest)에서 `SyncLingo-arm64.apk`를 폰으로 받아 설치합니다.

## 기능
- 유튜브 링크 붙여넣기, 또는 유튜브 앱에서 **공유 → SyncLingo**
- 영상(720p) 또는 오디오만 받기, 영어 자막과 한국어 자동번역 자막 함께 저장
- 문장 탭으로 해당 지점 재생, 현재 문장 강조와 단어 단위 하이라이트, 자동 스크롤
- 재생 모드: 연속 재생 / 한 문장 반복 / 문장마다 멈춤(쉐도잉)
- 속도 0.5~1.5배, 한국어 번역 표시, 받아쓰기 모드, 문장 북마크(길게 누르기)
- 다른 앱으로 받은 영상과 .srt/.vtt 자막 가져오기
- 다운로드 엔진(yt-dlp) 앱 안에서 업데이트, 하루 한 번 자동 업데이트

## 빌드
`main` 브랜치에 푸시하면 GitHub Actions가 APK를 빌드하고 릴리스로 올립니다.
서명 키(`keystore/release.jks`)가 저장소에 들어 있어서, 업데이트 APK를 기존 앱 위에 그대로 설치할 수 있습니다.
